# Sistema Streamlit

Um projeto interativo desenvolvido com **Streamlit** que demonstra componentes essenciais da biblioteca.

## 📋 Características

- **Home Page**: Formulário interativo com múltiplos tipos de entrada
- **Página de Gráficos**: Visualização de dados em tempo real
- **Menu Lateral**: Navegação entre páginas
- **Componentes Diversos**: Inputs, selectbox, slider, checkbox, botão e gráficos
